An implementation of CFDP for CSCI1680 Final Project and for BSE

Run `make` to build the executables in `bin/`; intermediate object files go in
`build/`. Run `make test` for the PDU unit tests. `make clean` removes both output
directories, legacy objects in `src/`, and the loopback output file.
